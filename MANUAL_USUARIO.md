# 📖 Manual de Usuario - ERP El Aromo (v2.5.0)

Bienvenido al sistema de gestión integral para la Panadería El Aromo. Este manual detalla las funcionalidades clave y el flujo de trabajo del sistema.

## 🔑 1. Acceso y Roles
El sistema utiliza un esquema de **Simulación de Perfiles** para facilitar la gestión por áreas:
- **Vendedores (Punto de Venta)**: Acceso a ventas rápidas y gestión de pedidos.
- **Panaderos (Gestión de Planta)**: Acceso a fórmulas, recetas y control de stock de insumos.
- **Gerencia (Administración)**: Visión global de KPIs, auditoría de ventas y reportes.

## 📊 2. Panel de Control (Dashboard)
Aquí encontrará el resumen operativo del día:
- **Exportación**: Los botones **EXCEL** y **PDF** generan reportes descargables de la actividad actual.
- **Métricas**: Verifique las ventas del día, pedidos urgentes y alertas de stock bajo (indicadas en rojo).
- **Registro de Actividad**: Seguimiento cronológico de todas las operaciones de la sucursal.

## 🛒 3. Punto de Venta (POS)
Para realizar una venta:
1. Seleccione los productos del catálogo (use el buscador para agilizar).
2. Ajuste las cantidades en el carrito.
3. Seleccione el **Método de Pago** (Efectivo, Tarjeta, MP).
4. Presione **FINALIZAR VENTA**. El sistema actualizará el stock automáticamente.

## 🍞 4. Gestión de Producción (Recetario)
Para iniciar un lote de producción:
1. Diríjase a la sección **PRODUCCIÓN**.
2. Seleccione una fórmula maestra y presione **INICIAR LOTE**.
3. Ingrese los Kg totales a producir; el sistema recalculará los insumos necesarios.
4. Utilice el **Checklist** para marcar los ingredientes a medida que los agrega.
5. Presione **FINALIZAR Y DESCONTAR** para registrar la merma de insumos en el inventario.

## 📦 5. Inventario y Recepción
Acceda desde el menú lateral para ajustar niveles de stock o desde el acceso rápido en el Dashboard para registrar la **Recepción de Productos**.
